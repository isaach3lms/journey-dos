{# The formatting toolbar for an email body. One partial, used by every screen that composes an email, so the buttons and the markers they insert cannot drift apart between the church-wide composer and the one on a person's page. Call it with the id of the textarea it belongs to: {% with target = "body" %}{% include "partials/_formatbar.html" %}{% endwith %} **The buttons type for you, they are not a different editor.** Pressing "Bulleted" puts "- " at the start of the line, which is exactly what somebody who knows the grammar would type. That keeps one source of truth for what an email contains: the characters in the box. A contenteditable field would instead mean the browser handing us HTML, and the whole reason app/markup.py exists is that HTML from a browser is HTML from whoever got into a leader's account. **The hint stays when the toolbar goes.** Without JavaScript the buttons would do nothing, so they are not rendered at all, and the line underneath still says what to type. That line is not a fallback nobody sees: it is how anybody learns the markers in the first place. #}
